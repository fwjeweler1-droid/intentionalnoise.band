First time here? How to link your recordings
  1. Choose a storage provider below, or select your own.
  2. Upload your full unpublished WAV or MP4 into a private folder with that provider.
  3. Authorize Connect using the provider's secure connection process when available. Otherwise supply a restricted share link.
  4. Choose who may request access. Do not paste a public link to confidential recordings.
  5. Show visitors an approved image or an MP4 Reel of no more than 60 seconds.

Connect records the owner, file pointer and requested permissions. The external provider must independently enforce access. No provider authorization is active in this preview.

START / MPCC Handoff

Authority: START and Music_Project_Command_Center.xlsx remain the authoritative Intentional Noise records. This site is a coordination layer, not their replacement.

Future backend should export dated, reviewable manifests for musicians, packets, version history, decisions, royalty terms, and file pointers; changes must pass explicit approval before authoritative writeback.

Security: Supabase Auth and row-level security govern Connect metadata. Third-party OAuth or provider ACLs govern actual files. Never expose service keys in the browser. Use short-lived links, least privilege, audit logs, and tested backups.
